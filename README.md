# Eri — portfolio site

A single-page product portfolio for Eri: selected work, how they work, and a clear contact path.

## Stack

- Next.js (App Router) + TypeScript
- Tailwind CSS
- shadcn/ui

## Run locally

```bash
npm install
npm run dev
```

Open [http://localhost:3847](http://localhost:3847).

## Customize

Edit content in `src/data/portfolio.ts` (name, projects, principles, email). Swap images under `public/images/`.

## Scripts

| Command        | Description              |
| -------------- | ------------------------ |
| `npm run dev`  | Dev server on port 3847  |
| `npm run build`| Production build         |
| `npm run start`| Serve production build   |
| `npm run lint` | ESLint                   |
